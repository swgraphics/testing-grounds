# Testing Grounds 1.6.03.02

## Focus
Tree interaction recovery, leaf vertex editing foundation, object library cleanup/place flow, terrain brush anchoring, shortcut invocation, Xbox navigation, block stack stamps, and FPV movement responsiveness.

## Included
- Tree HUD remains `OBJECT // TREE` while tree edit is active.
- Full branch parameter controls exposed in Tree Interaction.
- Leaf Vertex Editor opens as a dedicated window and writes the canonical leaf vertices into the procedural tree definition.
- Selecting an object immediately enters PLACE mode and begins preview.
- Custom object cards have delete controls with confirmation.
- Terrain brush target is locked for the duration of a sculpt gesture while the visual brush remains natural.
- Block stack height stamps are recomputed for the full stack after placement.
- SHORTCUTS can be toggled with V / the on-screen button; D-pad navigation remains normal panel navigation when the shortcut panel is closed.
- Xbox VIEW opens Editor; MENU opens Dev Tools.
- FPV movement acceleration is made more responsive; Crash Tester turn response is damped.

## Deferred
The full visual Compass radial hierarchy, Undo/Redo, generalized Scatter expansion, object rotation widget, block collision overhaul, and Canyon Edge Expansion remain subsequent passes.
